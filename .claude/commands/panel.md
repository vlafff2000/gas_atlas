Запусти скилл `pxg-expert-panel`. Аргументы: $ARGUMENTS

- Аргументов нет: облегчённый режим, без субагентов (критик расчётов в основном чате, только итоговые числа).
- Названы эксперты: запусти только их (не больше 4), независимых одним сообщением, затем критика расчётов последним.
- Воркерам: читать только указанные файлы и диапазоны строк, репозиторий не сканировать, ответ не длиннее 10 находок.
- Итог: сведённый список находок по серьёзности, без пересказа хода проверки.
