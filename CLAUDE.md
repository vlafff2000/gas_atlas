# Газовый атлас: правила работы над репозиторием

Версия 5.8 (Streamlit) удалена: остался **Атлас 6** (`atlas/` + `web/`), см. `docs/adr/ADR-001-architecture.md`. Расчётное ядро,
унаследованное от 5.8, лежит в `atlas/engine/` (core, modules). Как запускать, как устроено и как подключать модули — `docs/ATLAS6.md`.

## Расчёты
Проверенную математику (`atlas/engine/modules/`) не переписывай: в `atlas/modules/` — только выбор данных и представление.
Чек-листы переноса из 5.8 — `docs/parity/` (история). Изменение расчёта сопровождай тестом.

## Совместимость
Проекты, исключённые точки, журнал и сохранённые виды лежат в `storage/`. Формат не менять без миграции: старые проекты (в том числе созданные в 5.8) должны открываться.

## Проверка перед коммитом
- `python -m pytest -q tests` 
- `cd web && npx tsc --noEmit && npm run build` — собранный интерфейс `atlas/web/dist` лежит в git, CI это проверяет,
- новый интерфейс смотреть в браузере (`python -m atlas --server` и `npm run dev`), а не только по тестам.

## Прочее
Тексты для пользователя — по-русски; пустая выборка — заметка, а не ошибка; обе версии работают на Python 3.8+ (обычный CI проверяет 3.8, 3.11 и 3.13 — вручную, `all_pythons`; компьютеры компании, переносная сборка — `docs/PORTABLE.md`): без `dict | dict`, `match`, `str.removeprefix` и прочего 3.9+; аннотации — через `from __future__ import annotations`.
