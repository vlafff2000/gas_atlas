# Газовый атлас: правила работы над репозиторием

Две версии живут рядом: **5.8** (`app/`, Streamlit) работает, пока перенос не закончен; **6** (`atlas/` + `web/`) строится по
`docs/adr/ADR-001-architecture.md`. Как запускать, как устроено и как подключать модули — `docs/ATLAS6.md`.

## Главное правило переноса
Ни одна функция 5.8 не теряется. Перед переносом раздела выпиши все его функции в `docs/parity/<раздел>.md`
(образцы: `gdi.md`, `production.md`), закрывай пункты по списку, расхождения помечай «≈» с объяснением.
Раздел готов, когда закрыт весь чек-лист. Проверенную математику не переписывай: вызывай код из `app/modules/`,
в `atlas/modules/` — только выбор данных и представление. На каждый перенесённый расчёт — тест паритета со старой функцией.

## Порядок разделов
ГДИ ✅ → Производительность и Гистограммы ✅ → Графики реагирования → Кроссплот давлений → Группы и Аналитика фонда →
Поскважинный анализ и Паспорт → Импорт, Экспорт, Исключённые точки, История фильтра, Настройки → удаление 5.8.

## Совместимость
Проекты, исключённые точки, журнал и сохранённые виды общие с 5.8 (`storage/`, тот же формат): точку, исключённую в 6,
должна видеть 5.8, и наоборот. Формат не менять без миграции.

## Проверка перед коммитом
- `python -m pytest -q tests` (5.8 и atlas), 
- `cd web && npx tsc --noEmit && npm run build` — собранный интерфейс `atlas/web/dist` лежит в git, CI это проверяет,
- новый интерфейс смотреть в браузере (`python -m atlas --server` и `npm run dev`), а не только по тестам.

## Прочее
Тексты для пользователя — по-русски; пустая выборка — заметка, а не ошибка; Python для ядра 6 — 3.10+, 5.8 держит 3.8.
