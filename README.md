# Газовый атлас 5.8 (с обновлённым интерфейсом) · Python 3.8 и новее

Полная локальная версия приложения: динамика отбора и закачки, ГДИ, реагирование горизонтов, аналитика фонда, группы, постоянные проекты и экспорт. Светлая рабочая область, темная боковая панель и бирюзовые акценты из первой версии. Графики и экспорт без видимых водяных знаков.

## Windows

Нужен **CPython 3.8 или новее, 64-bit** (проверено на 3.8, 3.11 и 3.13). Для первой установки нужен интернет. Распакуйте архив в обычную папку, например `C:\GasAtlas`; затем:

1. Дважды нажмите `install_windows.bat`. Дождитесь сообщения `Installation complete`.
2. Дважды нажмите `run_windows.bat`. Браузер откроется автоматически.
3. Работайте по адресу **http://127.0.0.1:8501**. Оставьте окно приложения открытым. Остановка — Ctrl+C в этом окне.

Установщик ищет `py -3.8`, затем `python`. Если Python установлен отдельно, задайте путь в командной строке перед установкой:

```bat
set "GAS_ATLAS_PYTHON=C:\Python38\python.exe"
install_windows.bat
```

Зависимости устанавливаются в `.venv` рядом с приложением. Системные пакеты Python не изменяются. Существующее окружение другой версии не перезаписывается: используйте новую папку приложения. Для другого порта: `set GAS_ATLAS_PORT=8502` перед `run_windows.bat`.

## Linux

Нужен **CPython 3.8 или новее, 64-bit**, с модулем `venv`. Для первой установки нужен интернет. В терминале внутри распакованной папки:

```bash
bash install.sh
bash run.sh
```

Браузер откроется автоматически; адрес **http://127.0.0.1:8501**. Терминал должен оставаться открытым. Завершение — Ctrl+C. Без автоматического открытия браузера: `bash run.sh --no-browser`.

Установщик выбирает первый подходящий интерпретатор (`python3`, затем `python3.13` … `python3.8`); неподходящий интерпретатор отклоняется до установки. Явный путь: `PYTHON_BIN=/path/to/python bash install.sh`. Если система не содержит `venv`, установите пакет для используемого Python 3.8 средствами вашей системы. Другой порт: `GAS_ATLAS_PORT=8502 bash run.sh`.

## Что входит в архивы

В обоих архивах одинаковый полный код приложения, примеры входных таблиц, тесты, инструкции и зафиксированные зависимости. Различается инструкция быстрого запуска Windows/Linux. Подробности изменений — в CHANGES_v5.md. Python 3.8 ставит зафиксированные версии (requirements-lock-py38.txt), более новый Python — диапазоны версий (requirements-modern.txt).

Результаты фактически выполненных проверок и границы проверки Windows указаны в `VALIDATION.md`.

## Первые действия

1. Создайте проект в левой панели. Для ознакомления можно открыть **отдельный** демонстрационный объект: это синтетические данные, они помечены в интерфейсе.
2. В разделе «Импорт данных» выберите файлы либо вставьте таблицу из Excel. Укажите единицы для колонок без единиц в заголовке.
3. Нажмите «Проверить файлы». Изучите предпросмотр и журнал ошибок. При наличии отклоненных строк их исключение нужно подтвердить отдельным флажком.
4. Нажмите «Применить загрузку». С этого момента данные и исходные файлы сохранены в проекте.
5. Откройте «Динамика», «ГДИ» или «Реагирование», настройте выборку. В разделе «Экспорт» подготовьте архив с графиками и таблицами.

## Форматы входных данных

Поддерживаются `.xlsx`, `.xls`, `.csv`, `.tsv`, `.txt` и вставка таблицы с заголовками. XLSX читается последовательно в режиме read-only; большие таблицы обрабатываются порциями по 50 000 строк. После импорта сохраняются Parquet-файлы, повторно читать Excel не нужно. UTF-8 и Windows-1251, десятичная запятая и точка поддерживаются.

Одна книга может содержать листы разных модулей. Имена листов «Отборы» и «Закачка» распознаются. Для остальных листов динамики задайте тип в интерфейсе. Явный столбец «Тип данных» имеет приоритет над названием листа.

### Динамика

| Скважина | Дата | Расход | Сезон | Группа | Подгруппа |
|---|---|---|---|---|---|
| 73 | 01.11.2025 | 48000 | 2025-2026 | ГСП 9 | 1 |

Первые три поля обязательны. Единица по умолчанию — **м³/сут**. Если колонка содержит «тыс.» в заголовке либо выбран соответствующий переключатель, расход пересчитывается в м³/сут. Графики показывают тыс. м³/сут. Также принимаются матрицы: в первой строке номера скважин, в первом столбце даты, на пересечении расходы; верхняя левая ячейка пустая или «Дата».

### ГДИ

| Скважина | Дата | Q | Рпл | Рзаб |
|---|---|---|---|---|
| 31 | 10.12.2021 | 256.8 | 75.4 | 71.01 |

Q по умолчанию — **тыс. м³/сут**, давления — **кгс/см²**. В этом примере ΔP² = **642.7399 кгс²/см⁴**. В старой БД вместо пары давлений допускается колонка «Рпл2-Рз2» / `dp2`. Необязательные поля: `a`, `b`, `Метод`, `Исследование`, `Сезон`.

Все давления одной загрузки должны иметь одинаковые единицы. При выборе МПа давления пересчитываются в кгс/см², а ΔP², a и b — в соответствующие квадратные единицы. Коэффициенты БД считаются заданными в единицах Q исходной таблицы. При переходе из м³/сут в тыс. м³/сут автоматически применяются `a_тыс = 1000 × a_м3`, `b_тыс = 1000000 × b_м3`. Не смешивайте в одной таблице Q и коэффициенты, рассчитанные для разных единиц.

Одной датой нельзя объединять независимые исследования: заполните «Метод» и/или «Исследование», если на одной скважине в этот день было несколько исследований. Последние N означают последние N **дат**; исследования разных методов остаются отдельными.

### Реагирование

| Скважина | Дата | Горизонт | Уровень жидкости | Рпл привед |
|---|---|---|---|---|
| 132 | 11.01.2004 | Окский | 29,4 м | 71 |

Приведенное давление необязательно. Значение уровня — одно число, допускается единица «м». Текст «сухо», диапазон `10–20` и неоднозначные значения не превращаются в выдуманное число: они попадают в журнал ошибок. Цвет закрепляется за скважиной и одинаков для ее уровня и давления; все линии сплошные. В совмещенном режиме метры и давление используют независимые шкалы Y; уровень остается с обратной осью. По умолчанию графики строятся отдельно по горизонтам.

### Группы

Загрузите таблицу с заголовками `Скважина;Группа;Подгруппа`. Допускается только `Скважина;Подгруппа`: текущая группа сохранится. Для таблиц без заголовков выберите тип «Группы» (Скважина, Группа, Подгруппа) или «Подгруппы» (Скважина, Подгруппа). Назначения можно изменить и непосредственно в разделе «Группы».

## Правила расчетов

- Отбор по умолчанию: ноябрь–апрель. Явный «Сезон» имеет приоритет. Вне границ сезона данные сохраняются в «Вне сезона YYYY». Закачка — по календарному году или явно заданному «Год».
- Накопленный объем X — сумма суточных объемов **всего загруженного объекта**, включая текущую дату, в млн м³. Выбор скважин влияет на линии Y, но не меняет X. Накопление начинается заново в каждом периоде.
- Пропуск даты на кривой показывается нулем с пометкой в подсказке. Исключенное измерение образует разрыв, а его расход не входит в накопление и средние. В среднем пропуски и нули не участвуют. Средний дебит = сумма положительных расходов / число положительных записей / 1000. При единственной записи за сутки это среднее за активные дни; данные с несколькими замерами в сутки требуют предварительного суточного агрегирования.
- Средний по нескольким периодам взвешен по числу активных дней. Отрицательные расходы отклоняются.
- Повтор «тип + скважина + дата» в динамике не суммируется. Пользователь выбирает, оставить старое или новое значение. Для реагирования ключ включает горизонт. ГДИ при обновлении заменяется целиком по ключу «скважина + дата + метод + исследование», чтобы старые режимы не оставались рядом с исправленными.
- Для подбора ГДИ нужны хотя бы два разных положительных Q и положительных ΔP². Математический метод исходного `GDIAnalyzer.fit_trend_line` сохранен. Хорошие коэффициенты БД имеют приоритет при R² ≥ 0.95; иначе проверяется расчет; если оба плохие, доступны коэффициенты БД с явной отметкой качества.
- Две точки определяют два коэффициента, но не дают независимой проверки точности. Этот случай помечен в результатах. Нулевые точки сохраняются на диаграмме, но не используются при подборе.
- Qmax наблюд. — максимальный измеренный Q. Qсв — отдельная формальная экстраполяция уравнения при Рзаб = 0. Она не равна разрешенному режиму скважины и не выводится без Рпл либо при R² ниже порога. Давления должны быть приведены к единой системе отсчета пользователем; приложение не определяет абсолютное/избыточное давление по цифрам.
- Сравнение ГДИ по точкам: общий диапазон Q, интерполяция связанных пар (Q, ΔP²), порог изменения 10%. Меньше ΔP² при том же Q означает «Улучшение» в рамках этой метрики. Автоматическая причинная оценка КРС по одному сравнению не выполняется.

## Ручной фильтр точек

Включите **«Исключать точки кликом»** в боковой панели и нажмите измеренную точку. Она исключится из расчетов, графики перестроятся. Подсказки на расчетных кривых ГДИ показывают a, b, R², Q и ΔP²; сама расчетная кривая не является исходным измерением и кликом не исключается.

Под графиками есть **«Ручной фильтр точек»** с таблицей и страницами по 500 строк. Отметьте «Исключить», укажите причину и нажмите «Применить ручной фильтр». Для гистограмм исключайте исходные суточные измерения в этой таблице: столбик представляет агрегат, а не одну точку.

В разделе **«Исключенные точки»** доступно восстановление выбранных показателей, всех точек и отмена последней операции. Журнал можно скачать. Фильтр хранится в проекте и резервной копии; исходные данные не удаляются. Уровень и давление в одной строке реагирования исключаются независимо. В динамике исключение меняет средние и накопленный объем всего объекта; это отражается на всех выбранных скважинах.

## Предпросмотр и гибкая выгрузка

В «Экспорте» выберите модули, скважины, периоды, виды графиков и необходимые кривые. Кнопка «Взять параметры из вкладок просмотра» переносит текущие настройки; для динамики можно выгрузить обе настроенные панели. Чтобы параметры были доступны после перезапуска, сохраните их на вкладке модуля.

«Макет файла» показывает реальную статическую верстку при выбранной ширине с облегченным разрешением 150 DPI. «Интерактивный предпросмотр» поддерживает подсказки и исключение точек. Экспорт использует тот же набор данных и параметров; итоговый PNG получает выбранные 300/600/1200 DPI. При изменении параметров старый архив скрывается до повторного формирования.

Отметка «Применять исключения точек проекта» включена по умолчанию. Ее можно снять для выгрузки исходного набора. Экспорт с действующим фильтром содержит журнал исключений и параметры расчета.

## Обновление с версии 4

Распакуйте новую версию в отдельную папку. До обновления скачайте резервную копию проекта через «Настройки»; восстановите ее в v5. Для сохранения идентичности локальных проектов также можно перенести всю папку `storage` в остановленное новое приложение. Не смешивайте `.venv` разных установок. Исходники и резервная копия остаются у вас.

## Сохранение и перенос

Проекты находятся в `storage/projects/<идентификатор>/`. Данные — в атомарных снимках Parquet, настройки и назначения — в манифесте JSON, журнал — в `storage/history.sqlite`, исходные файлы — в `originals`. При одновременном редактировании одной версии во второй вкладке предлагается обновить страницу. Хранятся текущий и предыдущий снимки таблиц.

Через «Настройки» можно скачать `.gasatlas.zip` и восстановить его **отдельным** проектом. Копия содержит данные, настройки, группы, журнал CSV и, при выборе, исходники. При восстановлении создается новая история с записью восстановления; старый журнал остается внутри резервного архива.

Старую версию `.gas.json` откройте там же или на стартовой странице. Динамика, правила сезонов и группы переносятся в новый проект. Старый файл не изменяется. Перед обновлением приложения сохраняйте резервную копию; папку `storage` не удаляйте.

## Производительность и ограничения

- Лимит загрузки — 512 МБ на файл, распакованной книги — 3 ГБ. Это защитные границы, а не гарантия обработки файла любого устройства такого размера. Память зависит от числа ячеек, длинных строк и формата. Для крупных книг используйте CSV или деление по сезонам. Проверенные объемы и время указаны в `VALIDATION.md`.
- XLSX читается последовательно, но нормализованная таблица и результаты расчетов хранятся в памяти. XLS читается средствами xlrd; он менее подходит для больших наборов. Формулы Excel не исполняются: используются последние сохраненные значения. Файл с паролем нужно пересохранить без пароля.
- До 5000 точек на ряд в интерактивном отображении: выборка сохраняет минимумы и максимумы по окнам. Расчеты, табличные выгрузки и общий экспорт статических графиков используют полный набор.
- До 200 графиков на одну выгрузку, до 90 млн пикселей на один PNG. Для больших наборов выбирайте SVG/PDF или делите экспорт. XLSX ограничен 1 048 575 строками данных на лист: более длинные таблицы выгружаются в CSV.
- Веб-интерфейс доступен только с локального компьютера по умолчанию. Встроенных учетных записей нет. Развертывание для сетевой многопользовательской работы требует отдельной настройки доступа.

## Проверка и структура

```bash
bash test.sh
```

`app/core` — импорт, проекты и экспорт; `app/modules` — расчеты и графики; `app/ui` — оформление; `examples` — контрольные входные файлы; `tests` — проверки расчетов и интерфейса. `docs/MIGRATION.md` описывает перенос исходных правил и исправления. `VALIDATION.md` содержит результаты прогона и его ограничения.
