# Обновление интерфейса и импорта (поверх v5.8)

Основа: Gas Atlas v5 + накопительный патч v5.8. VERSION не менялся (5.8.0-py3820), чтобы не ломать проверки будущих патчей.

## Импорт
1. **Общий импорт: два режима.** «Простой»: перетащите все файлы, каждый лист классифицируется автоматически, проверка — в одной таблице (использовать / тип данных / распознанные поля / статус). «Подробный»: прежний редактор шапки и колонок по листам. Для нестандартного листа в простом режиме — «Тонкая настройка».
2. **Кроссплот давлений** — аналогично: «Быстрая» и «Подробная» загрузка.
3. **Исправлена ошибка «expanders may not be nested inside other expanders»** при загрузке нескольких файлов (вложенный блок замечаний внутри раскрывающейся панели).
4. **Скорость Excel.** Чтение .xlsx через python-calamine (Rust; openpyxl остается запасным вариантом): книга 34 МБ — было 70 с, стало 6 с. Нормализация даты / скважины считается по уникальным значениям. Для тяжелых случаев: выборка точек на экране, сжатые ящики и CDF, кэш фильтрации.
5. **Профили импорта.** «Запомнить для файлов с такой же шапкой»: раскладка колонок применяется автоматически (файл storage/import_profiles.json).

## Интерфейс
6. Кроссплот: фильтры сверху (кнопки «выбрано из всего»), результаты на всю ширину, сводка по сценариям. Переключатель «Закреплять панель фильтров» (боковая панель). ГДИ и Реагирование — те же панели фильтров в рамке.
7. «Экспорт» из кроссплота открывает вкладку «Кроссплот давлений» первой.

## Запуск
8. Python **3.8 и новее** (проверено 3.8-синтаксисом, 3.11, 3.12, 3.13). На 3.8 — зафиксированные версии (requirements-lock-py38.txt), на новых — диапазоны (requirements-modern.txt). install.sh / install_windows.bat выбирают подходящий интерпретатор.
9. Тесты: 63 (в том числе новые для импорта, профилей, больших данных); устаревшие тесты v5.0 обновлены. CI: .github/workflows/ci.yml (Python 3.8, 3.11, 3.13).

## Что намеренно не сделано
Замена parquet на SQLite/DuckDB: замеры показали, что хранение не узкое место (3,6 млн строк сохраняются за 3 с), время уходит на операции pandas; вместо миграции хранилища добавлены кэш фильтрации и выборка на экране.
