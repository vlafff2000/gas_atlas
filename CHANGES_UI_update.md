# Обновление интерфейса: «Кроссплот давлений» (поверх v5.8)

Основа: Gas Atlas v5 + накопительный патч v5.8 (применён). VERSION не менялся (5.8.0-py3820), чтобы не ломать проверки будущих патчей.

1. Панель фильтров перенесена наверх: Объекты / Сценарии / Группы / Фонды / Скважины (кнопки «выбрано из всего»), период, единицы, порог, цвет точек, «Без нулей», «Последние 3 года». Дополнительно: «Расчет», «График», «Оси», «Категории», «Сохранить», «Экспорт», «Группы».
2. Результаты на всю ширину: показатели, вкладки Кроссплот / Динамика / Распределения / Объекты / Статистика, область графиков. Рядом с кроссплотом — сводка по сценариям.
3. Новая «Быстрая загрузка»: перетащите все файлы сразу; роли (факт / модель / фонд), шапка и структура определяются автоматически, проверка — в одной таблице (роль, объект, сценарий правятся прямо в ней). «Тонкая настройка листа» и режим «Подробная (по листам)» сохранены. Новые объекты добавляются к существующим (или полная замена).
4. Большие объемы: файл читается один раз; кэш подробной загрузки увеличен (было 3 файла); выборка точек на экране, сжатые ящики и CDF; ограничение числа скважин на графиках динамики.
5. Тесты: tests/test_pressure_quick_import.py, обновлены tests/test_ui.py. Генератор тестовых книг: tools/make_pressure_samples.py.
