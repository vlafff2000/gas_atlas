# Газовый атлас 5.0 — Linux

Нужен Python 3.8 x64 или новее (проверено на 3.8, 3.11, 3.13). В терминале: `bash install.sh`, затем `bash run.sh`.

Адрес: http://127.0.0.1:8501

Подробная инструкция: README.md. Примеры: examples/. Изменения: CHANGES_v5.md. Результаты проверки: VALIDATION.md. Проекты сохраняются в storage/; перед обновлением скачайте резервную копию через «Настройки».
