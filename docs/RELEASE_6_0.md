# Газовый атлас 6.0 — первый рабочий релиз

Версия для использования на реальных объектах. Основа проверки: полная база одного ПХГ (882 тыс. строк добычи и закачки,
6,9 тыс. режимов ГДИ, 331 скважина), независимый пересчёт сумм из исходных таблиц, 460+ автотестов.

## Что нового по сравнению с рабочими версиями

- **Импорт реальных баз.** Книги со служебными листами загружаются; пустые дубли колонок игнорируются; таблица давлений скважин
  (скважина, дата, устьевое, пластовое) распознаётся как суточная эксплуатация; группы из колонки «ГСП»; названия групп
  в разных файлах приводятся к одному («ГСП_4» = «ГСП 4»).
- **Правильные суммы.** Дубли суток одной скважины не затирают расход нулём; составная скважина «54/80» делится поровну;
  группа скважины из эксплуатации главнее, чем из ГДИ; давление объекта за одну дату усредняется.
- **Статистика «открыта, но расхода нет».** Строки с временем работы и нулевым расходом сохраняются; в «Проверке данных» —
  по скважинам, группам (признак замерного узла) и месяцам.
- **ГДИ.** Исследование надёжно при не менее чем трёх разных режимах; без выбора скважин показываются первые пять.
- **Самопроверка на данных объекта.** `check_data_windows.bat` / `Proverka_dannyh.bat` / `proverka_dannyh.sh`: независимый
  пересчёт, физические и логические проверки, запуск всех разделов, отчёт `selfcheck_report.md` и `.json`.
- **Переносные архивы** для РЕД ОС 7.3+ (Linux x86_64, glibc 2.17+) и Windows 10+; проверяются в CI, в том числе в контейнерах
  CentOS 7 и AlmaLinux 8.
- **Память импорта.** Таблица после загрузки занимает вдвое меньше (306 МБ вместо 634 МБ на 835 тыс. строк).

## Известные ограничения

1. **Память при чтении Excel.** Чтение книги 30 МБ (800 тыс. строк) занимает около 0,9 ГБ в пике, около минуты. На компьютерах
   с 4 ГБ загружайте большие файлы по одному и закрывайте лишние программы. После загрузки проект работает с ~0,3 ГБ.
2. **РЕД ОС.** Проверено в контейнерах CentOS 7 (glibc 2.17) и AlmaLinux 8 (glibc 2.28); на самой РЕД ОС 7.3 запуск
   ожидает подтверждения. Атлас открывается в браузере.
3. **ГДИ при трёх-четырёх режимах.** Изменение коэффициентов a и b показывается, но оценка ориентировочная: небольшой разброс
   давлений даёт заметное изменение.
4. **Данные давлений для кроссплота** требуют роли «факт» и «модель» для листов; книги вида «все давления» без модели
   дают сообщение «нет ни одной пары».
5. **ГГХ** проверен на примере из поставки; на ваших отчётах проверьте импорт на одном файле.
6. **Составной номер «54/80»** делится поровну; другое правило (например, по доле в ГДИ) не поддерживается.
7. **Экспорт графиков:** SVG, PDF, PNG (300–1200 dpi); в Word-пакет графики вставляются как PNG.
8. **Один пользователь.** Проекты лежат в папке `storage` рядом с программой; совместная работа и блокировка файлов — на стороне
   пользователей.

## Системные требования

- Windows 10 и выше (64 бит) или Linux x86_64 с glibc 2.17+ (РЕД ОС 7.3+, Astra, ALT, CentOS 7+).
- 4 ГБ ОЗУ (8 ГБ для файлов от 30 МБ), 1 ГБ на диске для программы.
- Python не нужен: он лежит в переносном архиве (3.8).

## Как проверить объект перед работой

1. Запустите самопроверку на папке с файлами объекта (`docs/SELFCHECK.md`).
2. Откройте отчёт: пункты «ОШИБКА» разберите до анализа, «Внимание» — прочитайте.
3. Отчёт `selfcheck_report.json` можно отправить на разбор.
