# Чек-лист проверки выгрузки графика

Когда: после любой правки `chart_style.py`, `render.py`, `ChartView.tsx`, панели «Формат» и перед выпуском. Автоматически проверяется только то, что настройка
есть в окне «Формат» (`tests/test_chart_settings_coverage.py`); совпадение вида на экране и в файле смотрим глазами.

Как: взять один проект с данными, открыть график с несколькими рядами (линия, точки, столбцы) и двумя осями Y, выставить в «Формат» по одному значению из каждой
группы ниже и выгрузить во все форматы. Сравнить файл с экраном.

| Что выставить | Экран | PNG | SVG | PDF | Word | Excel |
|---|---|---|---|---|---|---|
| Заголовок, подзаголовок, выравнивание, шрифт, размер | ☐ | ☐ | ☐ | ☐ | ☐ | — |
| Фон графика и области построения, рамки | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |
| Сетка: основная и дополнительная, цвет, штрих | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |
| Легенда: место, колонки, рамка, фон; «Имя в легенде» | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |
| Оси: подписи (размер, поворот, формат даты, знаки), деления, линия, единицы ×10³ | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |
| Границы и шаг оси, разрыв оси, логарифм, обратное направление | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |
| Ряд: цвет, толщина, стиль, маркер (форма, размер, граница, полый), прозрачность | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |
| Подписи данных: положение, знаки, размер, угол, выбранные точки | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ (точки — все) |
| Тренд (с уравнением), погрешность, штриховка столбцов | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |
| Аннотации: линия, полоса, подпись | ☐ | ☐ | ☐ | ☐ | ☐ | — |
| Кириллица, минус у отметок TVDSS, пробел в разрядах «1 000» | ☐ | ☐ | ☐ | ☐ | ☐ | ☐ |
| Размер файла/DPI, поля и обрезка подписей осей | — | ☐ | ☐ | ☐ | ☐ | — |

Пустая ячейка или отличие от экрана — баг: сначала тест, потом правка. Виды для проверки: линии/точки/столбцы, график с несколькими осями Y,
спец-графики («Любой график»: тепловая карта, матрица, столбцы с сегментами; у них панель без осей).
