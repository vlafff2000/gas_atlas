## Новое в каркасе 6 (нужно для раздела)
- Виды параметров `date` (ISO-дата, пусто — умолчание модуля) и `text` (многострочное поле, пересчёт при выходе из поля).
- `TableAction(kind='assign')`: правка ячеек и отправка изменённых строк (`submit='changed'`) или всех (`submit='all'`).
- `Data.wells` — все скважины проекта по всем наборам (как `catalog['wells']` в 5.8).
- Модуль может не требовать данных (`needs=()`), работая с тем, что есть (`optional`).
