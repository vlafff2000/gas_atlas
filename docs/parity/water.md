# Вынос воды и водный фактор (новый раздел 6, без аналога в 5.8)

Источник: отчёт АН Касимовского ПХГ 2025, рис. 1.3–1.5 (стр. 25–27), табл. 1.6 (стр. 36). Модуль `atlas/modules/water.py`.
Данные: «Отбор и закачка» + «Контроль воды» (при отсутствии объёма воды в нём — «Суточная эксплуатация»).

- ✅ Накопленный вынос воды от объёма газа в пласте, линия на сезон отбора (рис. 1.3).
- ✅ Суточный водный фактор, л/тыс. м³ (рис. 1.4); накопленный водный фактор (рис. 1.5).
- ≈ Объём газа в пласте = стартовый (параметр, по умолчанию 0) + накопленная закачка − отбор по объекту с начала данных.
- ≈ Вода берётся по объекту целиком (сумма скважин на дату); колонки «число скважин» рис. 1.4 нет.
- ≈ Табл. 1.6 (ВФ по скважинам и сезонам) не строится: таблица «Вынос воды по сезонам» даёт ВФ по объекту.
- ✅ Экспорт SVG/PDF/PNG как у остальных графиков; ось X справа налево по умолчанию, как в отчёте.
