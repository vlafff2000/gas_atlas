# АН: единый холст и серия графиков по группам
- «Авторский надзор: сезон»: параметр «График» — ряды по суткам (холст), расход от накопленного объёма, средний расход по группам и месяцам, накопленный объём за сезон/месяц по группам, накопленный объём по месяцам для одной группы.
- Холст: ряды выбираются в «Ряды на графике» (расход объекта, среднее Рпл, скважины в работе точками, накопленный объём, вода, водный фактор, газ в пласте). Две шкалы Y: первая выбранная величина слева, остальные справа (единицы — в подписи шкалы).
- Ползунок оси X теперь появляется при ряде длиннее 14 суток во всех модулях (раньше 180).
- Не сделано (другие треды/PR): окно «Настройка» стилей рядов, переносимые названия графиков, третья ось Y. Ряды имеют стабильные имена/group для подключения.
- Код: atlas/modules/an_charts.py (canvas_chart, cum_*), an_report.py (VIEWS, season_charts); тесты в tests/atlas/test_an_report.py.
