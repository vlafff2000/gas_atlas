# Передача: КРС — приоритет ремонта и динамика ГДИ

- **Цель раздела:** по таблице «Анализ ревизии КРУ» собрать проведённые КР, статистику, потребность и приоритет КР (1 — срочно) и показать их в Атласе вместе с динамикой ГДИ.
- **Сделано:** скрипт `Анализ_технического_состояния_скважин_КРС` + `pxg_core/krs.py` в all_scripts (PR #338); модуль Атласа `atlas/modules/krs_status.py` («Авторский надзор: КРС — приоритет ремонта и динамика ГДИ»), читает `КРС_для_Атласа.xlsx`.
- **Решения:** приоритет выведен из «Потребности» таблицы (первая ревизия с песком после ремонта — 3, затем 2, 1; промывка/СКО не сбрасывают, замена фильтра и армирование сбрасывают; совпало на 81 из 88 клеток). После замены фильтра счёт заново с 3 (выбор Egor, скв. 56 — исключение). Ручной приоритет главнее и переносится (`--prev`). Ухудшение ГДИ (расчёт `gdi_trend`) — признак, приоритет не меняет.
- **Открытые вопросы:** скв. 40 (спец. ГДИ «нет песка», потребность в таблице пустая), 88 (столбцы потребности 2024–25 не заполнены); «прогноз на 5 лет» — очередь по приоритету с числом ремонтов за сезон (по умолчанию среднее замен фильтра за 3 года), логику Egor стоит подтвердить.
- **Не сделано:** автопополнение таблицы результатами КР (на будущее); вскрытия КРУ из актов Word читает отдельный модуль АН, здесь вход — таблица «скв. + песок».
