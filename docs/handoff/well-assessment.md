# Передача: оценка технического состояния скважины (паспорт)

- **Цель раздела:** по всем данным проекта оценить состояние скважины, подобрать критерии отбора в КРС и подсказать операцию; решает инженер.
- **Сделано (gas_atlas #574–#581):** плитки КРУ/КРС; ЭЛПРО с инструкцией; ядро улик `well_assess.py`; блок «Оценка состояния» с ручным решением; депрессия по сезонам с редактируемыми пределами; проверка на истории; пресеты списка ГДИ; таблица «механизм → операция» и сводка по фонду.
- **Файлы:** `atlas/well_assess.py`, `passport_assess.py`, `passport_depression.py`, `passport_elpro.py`, `passport_tiles.py`, `well_backtest.py`, `passport_blocks.py`, `api_passport.py`, `modules/gdi_due.py`, `web/src/PassportCard.tsx`.
- **Решения Egor:** метод «улики → механизмы → операция»; ручное решение главнее и не затирается; недоход до забоя при стабильной работе и забое из отчёта ГИС = шаблонирование геологами; источник забоя из столбца «Комментарий» БД шаблонирования; пределы депрессии 4,1 (расширка ПЗП) и 2,8 кгс/см² (перфорация), депрессия = Рпл−Рзаб.
- **Настройки проекта:** `well_assess`, `well_depression_type`, `depression_limits`, `well_operations`.
- **Открытые вопросы:** список механизмов и реальных операций (правится в таблице); значения пресетов «сдержанно/чувствительно» подобрать на истории; приоритет КР по ревизиям КРУ в проверку на истории не входит (нет даты); отдельная таблица ревизий вместо вывода по ГСП.
