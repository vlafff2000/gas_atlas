# Передача: «Эффект ремонта до и после»

- **Цель раздела:** по каждому проведённому КР показать расход и отдачу по ГДИ до и после рядом с изменением по группе; вывод делает инженер.
- **Сделано:** модуль `atlas/modules/repair_effect.py` (группа «Авторский надзор»), тесты `tests/atlas/test_repair_effect.py`.
- **Решения:** в `krs_works` только год, поэтому дата ремонта условная (1 июля по умолчанию, месяц меняется в параметрах); «до» — последний сезон отбора, закончившийся до даты, «после» — первый начавшийся после; 1–3 сезона усредняются. «Сверх группы» = изменение скважины − медиана группы за те же сезоны. Отдача — Q при общем ΔP² из `gdi_trend.histories` (последнее надёжное ГДИ до и первое после).
- **Открытые вопросы:** точные даты ремонтов (колонка в книге КРС) сделали бы оценку точнее; нужен ли график «до/после» (пока только таблица).
- **Следующий шаг:** график по выбранному ремонту; учёт простоев между ремонтом и сезоном.
- **Проверка:** `python -m pytest -q tests/atlas/test_repair_effect.py`. В браузере на реальном проекте не смотрел.
