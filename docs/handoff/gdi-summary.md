# Передача: «Справка ГДИ: итоги сезона и ремонты (КРС)»

- **Цель раздела:** графическая справка по итогам ГДИ сезона (улучшилось / не изменилось / ухудшилось) с разбивкой по категориям и отдельный разбор скважин с КРС за год.
- **Сделано:** `atlas/modules/gdi_summary.py` (группа «Исследования скважин»), тесты `tests/atlas/test_gdi_summary.py`. Графики на общем ядре (`Chart`/`Series`/`ChartTable`): стопка итогов по категориям, столбцы рядом, доли %, распределение изменения Q, итоги по годам КРС, ГДИ после ремонта по видам КРС. Таблицы: матрица «итог × категория» со списками скважин, таблица скважин сезона с основанием категории, таблица ремонтов года (ГДИ до/после).
- **Данные КРС:** читаются из `krs_works` (вид, год) и `krs_plan` (даты начала/окончания); нет даты — условно 1 июля года, это видно в таблице.
- **Категории (подсказка):** «После КРС: замена фильтра / промывка-СКО / армирование / прочее» (ремонт между сравниваемыми ГДИ), «ГДИ не делали более N лет», «Первое ГДИ», «Без КРС». Правка вручную — параметр «Категории вручную» (`скважина=категория`).
- **Решения:** сравнение — последнее надёжное ГДИ сезона против последнего надёжного до сезона (иначе первое надёжное в сезоне); порог по умолчанию 5 %, перерыв 5 лет — предложены нами. Нет данных = «Недостаточно надёжных», не нуль.
- **Открытые вопросы:** тип ремонта «промывка» берётся по словам «колтюбинг/СКО/промыв» в справке; нужны ли свои категории, кроме вида КРС; выгрузка справки в Word.
- **Проверка:** `python -m pytest -q tests/atlas/test_gdi_summary.py`.
