# Передача: «Справка ГДИ: предельные депрессии и расходы»

- **Цель:** технологическая карта по скважинам и группам: предел депрессии, расход по свежему ГДИ при этом пределе, падение расхода при снижении Рпл (шаг 10 кгс/см², настраивается).
- **Сделано:** `atlas/limit_flow.py` (расчёт), `atlas/modules/gdi_limits.py` (модуль, группа «Исследования скважин»), тесты `tests/atlas/test_limit_flow.py`, `test_gdi_limits_module.py`.
- **Метод:** Рпл² − (Рпл − dP)² = a·q + b·q² → q при каждом Рпл заново; a, b — из самого свежего надёжного ГДИ, неизменны (допущение, в справке сказано). Вне диапазона Qmax ГДИ (×1,2) — пометка «оценка грубая».
- **Предел:** вручную («скважина=значение») → ГДИ на вынос песка (`gdi_sand`, самое свежее исследование, источник и дата видны) → по типу забоя (расширка/перфорация) → не задан (расход не считается, не ноль).
- **Примечания:** песок в ревизиях КРУ (`krs_priority.sand`), давность ГДИ, оценка вне диапазона.
- **Дальше:** экспорт в Word/xlsx через общий экспорт; график Q(Рпл) по группам.
- **Проверка:** `python -m pytest -q tests/atlas/test_limit_flow.py tests/atlas/test_gdi_limits_module.py`.
