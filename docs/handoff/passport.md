# Передача: паспорт скважины — конструкция, дашборд, PDF

- **Цель:** паспорт показывает работу скважины (сезоны, Qmax, дни, ГДИ, КРС) и схему забойной части; дашборд в программе и та же страница в PDF.
- **Сделано:** `atlas/passport_card.py` (данные и фигуры схемы), `atlas/passport_card_pdf.py`, `web/src/PassportCard.tsx`, вкладки в `PassportPage.tsx`; `GET .../passport/card`, `card` в `POST .../passport/pdf`.
- **Решения:** на схеме только эксплуатационная колонна, НКТ, фильтр, перфорация, расширка, пакер, пласт, забой; ширина условная. КРС — из книги КРС_для_Атласа.xlsx (путь помнит браузер).
- **Открытые вопросы:** как в реальной конструкции называется расширка (распознаётся по «расшир/подзабой/каверн»); внутренний диаметр в своде не задан.
- **Не сделано:** КРС внутри проекта (сейчас отдельная книга); проверка в окне Windows и на реальных данных.
- **Проверка:** `python -m pytest -q tests/atlas/test_passport_card.py tests/atlas/test_passport.py`; `cd web && npx tsc --noEmit && npm run build`; страница смотрелась в браузере на демо.
