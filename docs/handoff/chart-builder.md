# Передача: конструктор графиков, этап 3 — комбинированные виды (до 15 строк)

- **Цель раздела:** свой график из любых полей проекта (план и решения Egor — `chart-builder/plan.md`, этапы 1–5).
- **Сделано:** этапы 1–2 (каркас, окна «Ряд»/«Ось»/«График»). Этап 3 — вид ряда: линия, точки, линия с точками, столбцы, область, ступенчатая;
  любая комбинация на осях Y1–Y5; поле «Стопка» у столбцов и областей; прозрачность окна «Ряд» у области и столбцов — заливка.
- **Файлы этапа 3:** `atlas/contract.py` (`Series.fill`, `Series.step`; `kind` не менялся, другие модули не затронуты), `atlas/modules/builder.py`
  (`VIEWS`, `row.stack`, `_stack_names`, `_on_grid`), `atlas/render.py`, `atlas/engine/core/export.py` + новый `export_combo.py`, `web/src/ChartView.tsx`,
  `chartHover.ts` (`Track.step`), `ChartBuilder.tsx`, `BuilderDialogs.tsx`, `ChartSettings.tsx`, тесты `test_builder.py`, `test_builder_export.py`.
- **Решения:** макет `layout` без смены версии: `series[].view` (новые значения) и `series[].stack`; новые ветки выгрузки включаются только для `chart.id == 'builder'`
  (`meta.combo`), старые графики рисуются как раньше; стопка идёт по номеру точки, поэтому ряды стопки приводятся к общему X (пропуск — NaN).
- **Открытые вопросы:** в XLSX столбцы, области и ступени рисуются линиями (данные полные); в PNG/SVG/PDF область с другой оси лежит над столбцами
  с прозрачностью (оси matplotlib), линии и точки всегда сверху; ширина столбцов на экране — авто ECharts (до 48 px), в файле — 0,8 шага данных ряда;
  в режиме «вид Excel» слои линий не разводятся.
- **Следующий шаг:** этап 4 — преобразования (накопленное, среднее, скользящее, нормировка) и калькулятор формул без eval.
- **Проверка:** `python -m pytest -q tests/atlas/test_builder.py tests/atlas/test_builder_export.py`; `cd web && npx tsc --noEmit && npm run build`
