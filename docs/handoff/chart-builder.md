# Передача: конструктор графиков, этап 5 — макеты и выгрузка (до 15 строк)

- **Цель раздела:** свой график из любых полей проекта (план и решения Egor — `chart-builder/plan.md`, этапы 1–5). Этапы 1–5 сделаны.
- **Этап 5:** библиотека макетов проекта (`atlas/builder_library.py`, маршруты `atlas/api_builder.py`, интерфейс `web/src/BuilderLibrary.tsx`): сохранить как,
  обновить, открыть, переименовать, дублировать, удалить (с подтверждением), экспорт/импорт JSON. Хранение — `settings['builder_layouts']` (версия 1), формат storage не менялся.
- **Выгрузка:** PNG/SVG/PDF — уже в значке загрузки графика; добавлены «Данные XLSX/CSV» (`render.chart_csv`) и Word одного графика (заголовок, подпись с полем SEQ).
- **Отчёт АН:** параметр `builder_layouts` у `an_report` — выбранные макеты идут рисунками в конце графиков (id `builder-<id>`); наборы отчёта прежние (объект, вода, план, МКД и др.), поля других наборов в макете дадут предупреждение «нет набора».
- **Решения:** макет с отсутствующими полями открывается с перечнем (`missing_of`), не падает; имена макетов уникальны без учёта регистра; `layoutOf` достраивает недостающие поля ряда (файл, написанный вручную).
- **Открытые вопросы:** рисунок макета в отчёте АН без подписи «Рисунок N» (подписи отчёта АН — отдельная выгрузка); Word отчёта АН делается общим экспортом;
  версия формата больше 1 отклоняется целиком; перенос макета между проектами — только файлом JSON.
- **По скважинам:** режим ряда «Текущая скважина» (`row.wells_mode='current'`, `layout.current_well`, оба необязательные; старые макеты как раньше) и `{скважина}` в заголовке, названии ряда и подписях осей (`builder.build(data, layout, well=None)`);
  выбор «Скважина макета» с ←/→ и поиском (`web/src/BuilderWells.tsx`); «Серия по скважинам» (`builder_library.series_file`, `POST /api/projects/{pid}/builder/series[/wells]`): PNG-zip, PDF (`grid_pdf`, страница на скважину), Word (`build_docx`, «Рисунок N»); не больше 200 скважин; без данных — пропуск с перечнем в заголовке `X-Atlas-Notes`. Отчёт АН: макет «текущей скважины» без `current_well` — предупреждение, рисунок пропущен.
