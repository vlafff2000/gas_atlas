# Передача: конструктор графиков, этап 1 — каркас (до 15 строк)

- **Цель раздела:** свой график из любых полей проекта (план и решения Egor — `chart-builder/plan.md`, этапы 1–5).
- **Сделано:** этап 1 — раздел «Конструктор графиков», каталог полей, ряды с ключом связи X↔Y, оси Y1–Y5, ручные подписи.
- **Изменённые файлы:** `atlas/modules/builder.py`, `atlas/contract.py` (вид параметра `json`, `Module.catalog`), `atlas/api.py`
  (`POST /api/modules/{id}/catalog`), `web/src/ChartBuilder.tsx`, `web/src/builder.css`, `App.tsx`, `ParamBar.tsx`, `api.ts`, `tests/atlas/test_builder.py`.
- **Решения:** макет — один параметр `layout` (JSON), поэтому история, «Сохранить макет» и localStorage работают как у других разделов;
  X из того же набора — построчно, из другого — по ключу, дубли X на ключ — среднее; пустые оси сжимаются (шкалы идут подряд).
- **Открытые вопросы:** единицы «Расход из МКП» и компонентов ГГХ не подписаны (нет в данных); агрегирование X «сумма» вместо «среднего» — этап 4.
- **Следующий шаг:** этап 2 — окна настройки ряда, осей и графика через существующее окно «Настройка» (`ChartSettings.tsx`).
- **Проверка:** `python -m pytest -q tests/atlas/test_builder.py`; `cd web && npx tsc --noEmit && npm run build`
