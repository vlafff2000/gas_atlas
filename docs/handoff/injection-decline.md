# Передача: Спад давления в конце закачки (до 15 строк)

- **Цель раздела:** универсальный анализ спада пластового давления в конце сезонов закачки: последние N сезонов (по умолчанию 5), для любого объекта или группы проекта.
- **Сделано:** модуль `injection-decline` (Эксплуатация): наложение давления по дням с начала закачки, суточная закачка, хвост сезона (45 сут) с давлением и темпом, таблица по сезонам, диаграмма «темп последнего месяца против спада».
- **Изменённые файлы:** `atlas/modules/injection_decline.py`, `tests/atlas/test_injection_decline.py`, `tests/atlas/test_inventory_snapshot.py` (слепок модулей).
- **Решения:** границы сезона берутся из `_seasonal.season_table`; максимум — наибольший замер внутри сезона; конец закачки — ближайший замер не позже 30 сут (`an_report.pressure_near`); давление — `an_report.object_pressure_of`. Подсказки с основанием выводятся в таблице. Параметр «Вручную» (JSON по сезонам: start, end, max_date, last_from) — последнее слово за инженером.
- **Открытые вопросы:** формат «Вручную» пока JSON, не таблица в интерфейсе; объём в таблице — по скважинам (не эталон узла учёта).
- **Следующий шаг:** проверка на реальном проекте Egor; при необходимости — визуальная правка «Вручную» в интерфейсе.
- **Проверка:** `python -m pytest -q tests/atlas/test_injection_decline.py tests/atlas/test_inventory_snapshot.py tests/atlas/test_contract.py`
